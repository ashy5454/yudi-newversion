Developer Integration

Deploy CTS locally as a Model Context Protocol (MCP) server for agents, or integrate the cloud SDK directly into your web applications.

Run CTS locally inside Claude Code, Cursor, or Windsurf to give your terminal agents persistent, infinite workspace memory: 

npx cts-mcp

Or add it to your claude_desktop_config.json: 

{
  "mcpServers": {
    "cts-mcp": {
      "command": "npx",
      "args": ["-y", "cts-mcp"]
    }
  }
}

Import the client library as a drop-in replacement for standard LLM SDKs to automatically run compression server-side: 

import { CTSClient } from '@yudi/cts';

// Setup client to route through CTS engine
const client = new CTSClient({
  provider: 'openai',
  apiKey: process.env.OPENAI_API_KEY,
  ctsKey: process.env.CTS_API_KEY // Get from dashboard
});

// History is automatically compressed and managed per sessionId
const response = await client.chat.completions.create({
  model: 'gpt-4-turbo',
  sessionId: 'user_session_948', 
  messages: [{ role: 'user', content: 'Restore our conversation history.' }]
});
